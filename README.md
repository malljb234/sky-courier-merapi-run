Merapi Vector (Elang-7) — Volcano Chase Flight: fly Operation Merapi Vector (OP-MV-07) as callsign Elang-7 over a volcanic island at golden morning, in formation with a wingman, with Mount Merapi smoking beyond the airstrip. Thread eight glowing gates down the river valley, bring her home for a gentle touchdown on the mountain airstrip, and drop supply crates onto the painted zones. Pure Canvas 2D with no libraries and no network requests: the whole island is procedural, the volcano and its smoke are drawn from a real position in the world, the instruments are lit glass meant to be flown, and every sortie asks for a different kind of flying — speed and line, patience and throttle, or low and slow.

## Run it

```sh
python3 -m http.server 8080 --directory game
# open http://localhost:8080
```

Arrows / WASD steer, Shift / Ctrl throttle, Space acts, P pauses, M mutes. Mouse and touch work too. `?shot=cover|rings|drop|landing&seed=1` stages the four screenshots deterministically.
